@@n01@@wreck. Don't merge agents. Merge proven state transitions. A deterministic governor for AI agents pushing code to the same repo.
@@n02@@Git records competing states, but it never knows why an agent made a change. When agents merge on vibes, broken code ships.
@@n03@@Picture fifty AI agents pushing to the same repo at once. The real problem isn't textual. Two agents can touch different files that implement the same invariant, and Git will happily merge them into a broken system.
@@n04@@wreck treats every change as a claim: intent, evidence, and semantic scope. A deterministic governor — written in Rust, with no language model in the decision path — classifies conflicts and issues verdicts. Every verdict is a sealed, hash-chained receipt.
@@n05@@The scenario: five agents, one authentication subsystem. Agent A hardens token validation. B shortens token expiry. C rewrites retry logic. D touches error semantics. E adds tests that depend on A. Watch the governor decide, live, on real Git.
@@n06@@We run the demo. cargo run, dash p, wreck-demo.
@@n07@@All five agents propose changes concurrently against the same baseline. Two canon rules are active — contracts the agents agreed to, enforced every time. The governor pulls each claim, checks its evidence, and maps its semantic scope.
